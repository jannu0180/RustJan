RustJanBridge 1.4.0 — server update / serveri uuendus

EESTI
Asenda serveri oxide/plugins/RustJanBridge.cs selle kausta uue failiga.
Kontrolli serverikonsoolist kompileerimist; vajadusel oxide.reload RustJanBridge.
CountryGuardi pluginat ega selle andmebaase ei pea selle uuenduse tõttu muutma.

Uus: rustjan.layers 1 1 annab magavad mängijad ja TC-de asukohad koos TC paigaldaja
SteamID-ga. See ei ole kõigi maja omanike ega TC autoriseeritud mängijate nimekiri.
TC tähistab ehitusõiguse kapi asukohta, mitte kogu hoone piire.
RustJan küsib neid kihte ainult avatud LiveMapil ja valitud linnukestega, iga 15 s.
Kumbagi kihti piiratakse 10 000 objektiga; piirangu korral näitab rakendus teadet.
Uus rustjan.items väljastab serveri tegeliku ItemManageri esemeloendi.
Kõik need käsud on ainult serverikonsooli/RCON-i jaoks. Mängijatele ei anta ligipääsu.
1.3.0 jätkab tavalise kaardi ja lennusündmuste väljastamist; uued kihid vajavad 1.4.0.
Rusti/Oxide teegid puuduvad arendusarvutis, seega kinnitab päris API ühilduvuse
serveri kompileerimine. Igakuist kohustuslikku muutmist ei ole.

ENGLISH
Replace oxide/plugins/RustJanBridge.cs on the Rust server with the updated file.
Check server compilation; use oxide.reload RustJanBridge if necessary.
No CountryGuard/database update is needed for this release.
New read-only RCON commands: rustjan.layers <sleepers 0/1> <TCs 0/1>, rustjan.items.
TC markers show the cupboard position and its OwnerID (placer), not a definitive
list of building owners or authorized players. Layers refresh every 15 s only
while selected and the map is visible, capped at 10,000 objects per layer.
Item catalogue uses the running server's ItemManager definitions.
Version 1.3.0 retains its original map/events functions; new layers require 1.4.0.
Verify compilation against your actual Rust/Oxide server libraries after upload.
