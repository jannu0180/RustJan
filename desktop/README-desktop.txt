RUSTJAN 1.5.3 — WINDOWS DESKTOP TEST / TÖÖLAUARAKENDUSE TEST

ENGLISH
Run RustJan.exe. No browser, Node.js installation or administrator rights are needed.
Keep all files in this folder together; RustJan.exe uses the included runtime files.
The X button hides the window to the system tray. Monitoring, logging and statistics continue.
Click the orange RJ tray icon or choose Open RustJan to return to the window.
Choose Exit RustJan in the tray/application menu to stop and save data properly.
Saved server profiles, encrypted passwords, logs, player history, maps and statistics are stored beside the executable in conf/ and logs/.
Saved servers reconnect on launch if a saved password is available. This can be switched off in the RustJan menu.
A second launch opens the existing window rather than creating another monitoring process.
Do not run the web version and the desktop version against the same data folder at the same time.
This is the desktop test build, not an installer. No desktop shortcut or automatic update is installed yet.
Server plugin: copy server-plugin/RustJanBridge.cs to the Rust server oxide/plugins directory if needed.

EESTI
Käivita RustJan.exe. Eraldi brauserit, Node.js-i paigaldust ega administraatori õigusi pole vaja.
Hoia kõik selle kausta failid koos; RustJan.exe kasutab kaasasolevaid käitusfaile.
Akna X-nupp peidab rakenduse süsteemisalve. Jälgimine, logimine ja statistika jätkuvad.
Akna avamiseks klõpsa oranžil RJ-ikoonil või vali Ava RustJan.
Korralikuks sulgemiseks ja andmete salvestamiseks vali salve/rakenduse menüüst Välju RustJanist.
Serveri profiilid, krüpteeritud paroolid, logid, mängijaajalugu, kaardid ja statistika asuvad exe kõrval conf/ ja logs/ kaustades.
Salvestatud serverid ühendatakse käivitamisel, kui parool on salvestatud. Selle saab RustJani menüüst välja lülitada.
Teistkordne käivitamine avab olemasoleva akna, mitte uut jälgimisprotsessi.
Ära käivita sama andmekausta kasutavat veebi- ja töölauaversiooni korraga.
See on töölauarakenduse testversioon, mitte installer. Töölaua otseteed ega automaatset uuendamist veel ei paigaldata.
Serveriplugin: vajadusel tõsta server-plugin/RustJanBridge.cs Rusti serveri oxide/plugins kausta.
